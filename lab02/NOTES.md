git status - статус ветки, изменений
git diff - конкретно измененные строки кода
git diff --staged - изменения готовые к коммиту
ветка - ответвление кода, продолжение кода не изменяющее основную его часть
рабочая папка - папка с основным кодом
коммит - отправка в локал
индекс - момент готовности к коммиту
